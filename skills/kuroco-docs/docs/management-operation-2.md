# メールログ

> 元ページ: `management/mail-log-list` ｜ 公式ページ: https://kuroco.app/ja/docs/management/mail-log-list/

メールログではメール送信に関するログを確認できます。

## メールログの確認方法
[オペレーション] -> [ログ管理]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/bec37ecc842bbf4422d0bb77e4f6b3d2.png)

ページタイトルの上の[ログ管理]をクリックし、表示されたプルダウンの中にある[メールログ]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/29d6a4489ddd3fbdfc9f735f747d3e93.png)

## メールログの項目説明

![Image from Gyazo](https://t.gyazo.com/teams/diverta/10e316327842087a2a078608f0fcc583.png)

メールアドレスに対して```202 Accepted```となっていれば、SendGridへの送信は成功しています。  
メールの送信に失敗している場合などもこちらのログに残りますので、ご確認ください。

### 絞り込み条件

メールログではキーワードやログ日時による絞り込みと、詳細検索を用意しています。

#### キーワードによる絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/a1578208a275de84ba3062d4f18d37b8.png)

[キーワード] テキストボックスに検索するキーワードを入力します。キーワードを含むログを絞り込みます。

#### ログ日時による絞り込み

![Image from Gyazo](https://t.gyazo.com/teams/diverta/4549ed65460c690476b9cf512caebba9.png)

ログ日時の開始と終了で期間選択します。選択した期間のログを絞り込みます。  
指定できるログの期間は35日間となります。過去のログ日時を指定する場合も35日間の範囲となるように指定してください。

#### 詳細検索

[詳細検索] ボタンをクリックすると、絞り込み条件を作成できます。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/4d41ee535440447664878edba87d6fa9.png)

絞り込み対象として指定できる項目は次の通りです。

| 項目 | 説明 | 指定できる条件 |
| :--- | :--- | :--- |
| ホスト | メール送信が行われたサイト   | [検索条件](#検索に利用できるオペレーションについて) |
| ログレベル | メッセージの重要度を示すログレベル | [レベルについて](#レベルについて)を参照してください。 | 
| 宛先メールアドレス | メール宛先 | [検索条件](#検索に利用できるオペレーションについて) |
| HTTPレスポンスコード | HTTPレスポンスステータスコード | [検索条件](#検索に利用できるオペレーションについて) |
| レスポンス | HTTPレスポンス | [検索条件](#検索に利用できるオペレーションについて) |
| 件名 | メールの件名   | [検索条件](#検索に利用できるオペレーションについて) |
| URI | リクエストが行われたエンドポイントのURI   | [検索条件](#検索に利用できるオペレーションについて) |
| 送信元IPアドレス | アクセスしたユーザーのIPアドレス   | [検索条件](#検索に利用できるオペレーションについて) |
| メンバーID | アクセスしたユーザーのメンバーID   | [検索条件](#検索に利用できるオペレーションについて) |
| アプリケーション・リクエストID | Kurocoのリクエスト識別子 | [検索条件](#検索に利用できるオペレーションについて)  | 
| ユーザーエージェント | アクセスしたWebブラウザのユーザーエージェント   | [検索条件](#検索に利用できるオペレーションについて) |

詳細検索は複数の条件をAND、またはORで連結できます。ANDの場合は指定した条件すべてにマッチするデータのみを対象とします。OR条件は指定した条件のいずれかにマッチするデータを対象とします。

##### 検索に利用できるオペレーションについて

検索では次のオペレーションが指定できます。

| オペレーション   | 型 | 対象となるデータ |
| :---               | :--- | :--- |
| 含む            |  文字列 | 条件が一部に一致するデータ |
| 含まない        | 文字列 | 条件がいずれにも一致しないデータ |
| =               | 文字列・数値 | 条件に一致するデータ |
| !=              | 文字列・数値 | 条件に一致しないデータ |
| <               | 文字列・数値 | 条件未満のデータ |
| >               | 文字列・数値 | 条件より大きいデータ |
| <=              | 文字列・数値 | 条件以下のデータ |
| >=              | 文字列・数値 | 条件以上のデータ |
| で始まる         | 文字列 | 条件ではじまるデータ |
| で始まらない     | 文字列 | 条件ではじまらないデータ |
| で終わる         | 文字列 | 条件で終わるデータ |
| で終わらない     | 文字列 | 条件で終わらないデータ |
| どれかを含む     | 文字列・数値 | 条件を複数指定し、いずれかの条件に一致するデータ |
| どれも含まない   | 文字列・数値 | 条件を複数指定し、いずれの条件にも一致しないデータ |

##### 並び順について

ソートキーと表示順を選択することで検索結果の並び順を指定できます。並び順はASC（昇順。小さい方から大きくなっていく）またはDESC（降順。大きい方から小さくなっていく）を指定できます。

### ログ一覧項目

ログとして一覧されるデータの項目は次の通りです。

| 項目 | 説明 |
| :--- | :--- |
| ログ日時 |ログの記録された日時を表示します。 |
| ホスト | メール送信が行われたサイトを表示します。|
| ログレベル | メッセージの重要度を示すログレベルを表示します。詳細は[レベルについて](#レベルについて)を参照してください。 |
| 宛先メールアドレス | メール宛先を表示します。 |
| HTTPレスポンスコード | HTTPレスポンスステータスコードを表示します。 |
| レスポンス | HTTPレスポンスを表示します。|
| 件名 | メールの件名を表示します。 |
| URI | アクセスしたページのURIを表示します。 |
| 送信元IPアドレス | アクセスしたユーザーのIPアドレスを表示します。 |
| メンバーID | アクセスしたユーザーのメンバーIDを表示します。 |
| アプリケーション・リクエストID | Kurocoのリクエスト識別子を表示します。|
| ユーザーエージェント | アクセスしたWebブラウザのユーザーエージェントを表示します。 |

#### レベルについて

メッセージの重要度を示すレベルは以下の3段階があります

- warn
- notice
- info

# 承認ワークフロー

> 元ページ: `management/workflow` ｜ 公式ページ: https://kuroco.app/ja/docs/management/workflow/

承認ワークフローでは作成された承認ワークフローの一覧を確認・追加・更新できます。

## 承認ワークフロー一覧
### 確認方法
[オペレーション] -> [承認ワークフロー]をクリックします。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/4675743a6d59f15a52882e6e4703ab8b.png)

### 項目説明
![Image from Gyazo](https://t.gyazo.com/teams/diverta/e308011c61b3affa0a45b258c0f50823.png)

|項目|説明|
|---|---|
|ID|ワークフローのID番号です。自動採番されます。|
|ステータス|ワークフローのステータスが[有効]または[無効]で表示されます。|
|名前|ワークフローの名前です。|
|更新日時|ワークフローの更新日時です。|

### 一括処理
![Image from Gyazo](https://t.gyazo.com/teams/diverta/b5110d754c7a3a43350fdc8b4212c358.png)

一覧の左端のチェックボックスにチェックを入れて、下記いずれかをクリックすると、選択したワークフローに対して一括で処理を行います。

|項目   |説明  |
| :--- | :--- |
|有効にする|ワークフローを有効にします。|
|無効にする|ワークフローを無効にします。|
|削除する|ワークフローを削除します。|

#### 基本設定

|項目   |説明  |

## 申請中データに対する操作
承認対象コンテンツの編集画面から申請すると、申請中データが作成されます。
申請中データの画面では、承認ワークフローの設定に応じて以下の操作ができます。

![Image from Gyazo](https://i.gyazo.com/1690f0d7aa3ff4755cc16a71d6745429.png)

### 承認する
承認者が[承認する]をクリックすると、現在のフェーズの承認が完了します。
フロー設定で設定したすべてのフェーズの承認が完了すると、申請内容がコンテンツに反映されます。

### 差し戻す
承認者が[差し戻す]をクリックすると、申請を差し戻します。

[基本設定]タブの[中間フェーズへの差し戻しを許可]と[別ワークフローへの差し戻しを許可]がどちらも無効の場合は、申請者に差し戻されます。
いずれかが有効の場合は[差し戻し先を選択]ダイアログが表示され、以下から差し戻し先を選択できます。

![Image from Gyazo](https://i.gyazo.com/1266b14127f9557c309f32b8232d17f2.png)

|項目   |説明  |
| :--- | :--- |
|申請者|申請者に差し戻します。|
|差し戻し先を選択する|途中の承認フェーズを選択して差し戻します。[中間フェーズへの差し戻しを許可]が有効で、差し戻し先にできる中間フェーズがある場合に選択できます。|
|別のワークフローに移動する|申請を差し戻して、選択した別のワークフローで再処理します。[別ワークフローへの差し戻しを許可]が有効で、移動できるワークフローがある場合に選択できます。|

### 取り下げ
[基本設定]タブの[申請者の取り下げを許可]が有効な場合、申請中データの画面に[取り下げ]ボタンが表示されます。
申請者が[取り下げ]をクリックすると、自身の申請を取り下げることができます。

![Image from Gyazo](https://i.gyazo.com/6a90049efe1ba975309e8c9765bd62dd.png)

取り下げを実行すると、以下の通知・処理が行われます。

- 申請が取り下げられ、申請内容は途中保存データとして残ります。
- 現在の承認フェーズでメール通知が有効になっている承認者と、[基本設定]タブの[メール通知]で設定したメールアドレスに、「取り下げのお知らせ」メールが配信されます。
- トリガー「承認ワークフローの取り下げ後」が実行されます。詳細は[カスタム処理に利用できるトリガと変数の一覧](/ja/docs/reference/trigger-variables/#承認ワークフローの取り下げ後)を参照してください。

# ワークフロータグ

> 元ページ: `management/workflow-tags` ｜ 公式ページ: https://kuroco.app/ja/docs/management/workflow-tags/

ワークフロータグではワークフローに設定するタグの一覧を確認・追加・更新できます。
公開されたワークフロータグはワークフロー利用時に設定できます。

![Image from Gyazo](https://t.gyazo.com/teams/diverta/975c331cbf67eb9b11ff7f9c3e1f5a13.png)

### 項目説明
![Image from Gyazo](https://t.gyazo.com/teams/diverta/7f45fc8b201973d2144c12a68f15f983.png)

| :--- | :--- |
|検索|設定した条件でワークフロータグの検索ができます。|
