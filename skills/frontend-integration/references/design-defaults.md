# デザインの既定ルール

Kurocoサイトの画面を新規実装・変更するときに適用する。これは一時的なモデル対策ではなく、このスキルが採用するデザインの既定方針である。

## 優先順位

1. ユーザーが明示したデザイン指定と既存ブランド・UI
2. 本文書の既定ルール
3. `frontend-design` など、併用するデザインスキルの提案

`frontend-design` の指針と本文書が競合するときは本文書を優先し、競合しない指針は併用する。AIが独自に選んだ参考デザインを理由に、上位の指定や本ルールを上書きしない。

## 既定ルール

- **不自然な位置で改行しない。** 文節の途中へ `<br>` を入れず、画面幅に応じた自然な折り返しを基本にする。見出しやキャッチコピーを意図的に改行するときは意味のまとまりで区切り、対象画面幅で確認する。
- **見出し・キャッチコピーに句読点を多用しない。** 読点「、」と句点「。」は本文に使い、見出しでは原則として削る。句読点で長文をつなぐのではなく、言葉を絞って短くする。
- **角丸は `2〜4px` を基本とし、`0` も選択肢にする。** カードやボタンを習慣的に大きく丸めない。
- **短い単語やラベルを装飾目的の箱で囲まない。** 枠や背景は、操作できることや状態など、囲む意味がある場合に限る。
- **ブランド指定がない場合、earthy／オーガニック／クラフト系の色域を既定案にしない。** 配色はブランド、コンテンツ、利用場面から選ぶ。

## 見直し方針

モデルの更新だけを理由に廃止しない。生成結果の比較や利用者のフィードバックから、ルールがデザイン品質を下げる、または不要な制約になっていると確認できた場合に見直す。
